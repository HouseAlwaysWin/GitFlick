# GitFlick

## Agent skills

Configuration for the engineering skills. Each pointer file under `docs/agents/` holds the
details — edit those directly to adjust; re-running the setup skill is only needed to switch
issue trackers or start over.

### Issue tracker

Issues and PRDs live in **GitHub Issues** for `HouseAlwaysWin/GitFlick`, driven by the `gh` CLI.
See `docs/agents/issue-tracker.md`.

### Domain docs

**Single-context** — one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
